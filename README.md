# homebrew-brosh

Homebrew tap for [brosh](https://github.com/elleryfamilia/brosh) - the AI-native terminal.

## Install

```bash
brew tap elleryfamilia/brosh

# Desktop app (macOS)
brew install --cask brosh

# CLI only
brew install brosh-cli
```

## Uninstall

```bash
brew uninstall --cask brosh
brew uninstall brosh-cli
brew untap elleryfamilia/brosh
```
